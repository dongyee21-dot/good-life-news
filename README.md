# 좋은 삶

교육, 문화, 건강, 기후와 환경, 공동체 이야기를 소개하는 정적 웹사이트입니다.

## 사용 방법

`index.html`을 열면 첫 화면을 볼 수 있습니다. 메뉴와 기사 제목을 눌러 분야별 내용, 기사, 매체 소개를 읽을 수 있습니다. `support.html`은 후원 화면의 견본이며 실제 결제는 이루어지지 않습니다.

이 웹사이트는 HTML, CSS, JavaScript만 사용하므로 GitHub Pages에 그대로 올릴 수 있습니다.

## 기사 작성 도구

`admin.html`을 열면 제목, 분야, 작성자, 날짜, 요약, 본문을 입력해 새 기사 HTML 파일을 만들 수 있습니다. 이 도구는 기사 파일만 내려받으며 사이트에 자동 게시하지는 않습니다.
