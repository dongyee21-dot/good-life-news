새 기사 작성

아래 내용을 채우면 좋은 삶의 기사 모양으로 HTML 파일을 만들어 줍니다.

분 단위 숫자
비워 두면 날짜를 넣어 자동 생성합니다.
빈 줄을 기준으로 문단이 자동으로 나뉩니다.

사용 순서

  1. 기사 내용을 입력합니다.작성 중인 내용은 자동으로 임시 저장됩니다.
  2. 기사 파일 만들기를 누릅니다.HTML 파일이 다운로드 폴더에 저장됩니다.
  3. 저에게 게시를 요청합니다.다운로드한 파일을 이 대화에 첨부하고 “이 기사를 올려줘”라고 말해 주세요.
